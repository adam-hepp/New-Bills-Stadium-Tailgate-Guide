# 🏈 New Bills Stadium Tailgate Guide

An interactive tailgate map for Buffalo Bills fans showing private parking lots around Highmark Stadium — including pricing, walk time to the gate, and accepted payment methods (cash, Venmo, Zelle, etc.).

## 🛠 Tech Stack
- HTML, CSS, JavaScript
- Interactive map with hover tooltips

## 📦 How to Run Locally
1. Clone this repo: `git clone https://github.com/adam-hepp/New-Bills-Stadium-Tailgate-Guide.git`
2. Open `index.html` in your browser
